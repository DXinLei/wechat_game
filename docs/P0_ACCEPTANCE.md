# P0 v0.1 Acceptance Checklist

## Environment
- [ ] 微信开发者工具可以成功导入项目
- [ ] 项目类型为小游戏
- [ ] 编译无阻塞错误
- [ ] 控制台无致命报错

## Startup
- [ ] 游戏启动后显示标题「萌萌合成小恐龙」
- [ ] 显示第 1 关
- [ ] 显示目标 Lv.2 × 1
- [ ] 显示 3×3 棋盘
- [ ] 初始棋盘有 3 只恐龙（圆形占位，显示 Lv.1）

## Merge
- [ ] 点击恐龙后有黄色选中高亮边框
- [ ] 点击同等级恐龙后成功合成
- [ ] 合成后目标格等级 +1，源格被清空
- [ ] 合成后随机掉落一只新恐龙
- [ ] 再次点击同等级可继续合成

## Level Result
- [ ] 达成目标（棋盘有 Lv.2 × 1）后出现「🎉 通关！」提示
- [ ] 通关后「下一关」按钮变为绿色可用状态
- [ ] 普通状态下「下一关」按钮为灰色不可用
- [ ] 失败状态下（棋盘满且无法合成）「💔 游戏结束」提示
- [ ] 失败后「下一关」按钮为灰色不可用
- [ ] 「重开」按钮在任何状态下都可用

## Button Interactions
- [ ] 游戏结束后点击棋盘格无反应（不崩溃）
- [ ] 点击「重开」重新初始化当前关
- [ ] 通关后点击「下一关」进入第 2 关
- [ ] 失败后点击「下一关」无反应（不跳关）
- [ ] 普通状态下点击「下一关」无反应（不跳关）
