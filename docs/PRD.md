# 萌萌合成小恐龙 PRD v2.1：微信小游戏 MVP 可上线版

> 版本：v2.1
> 日期：2026-05-23
> 状态：草稿
> 核心定位：体验优先，广告顺手变现，不做强制分享激励

---

## 1. 产品概述

**产品名称：** 萌萌合成小恐龙
**类型：** 微信小游戏（休闲合成类，Q版萌系）
**商业模式：** 激励视频广告变现（无内购，无版号需求）
**一句话描述：** 玩家在九宫格棋盘上拖拽合成小恐龙，挑战关卡收集图鉴，体验轻量收集乐趣；卡关时主动选择观看激励视频获取复活/道具，广告作为服务体验的补充而非强制门槛。
**对标产品：** 羊了个羊（变现逻辑）、Pokémon Merge（合成玩法）
**合规原则：** 不做任何形式的强制分享激励，广告是用户主动选择，不是功能门槛

## 2. 合规红线（优先级最高）

### 2.1 禁止设计（绝对不可突破）

| 禁止项 | 原因 |
|--------|------|
| 分享微信群获得道具/复活/金币 | 微信平台明确禁止通过分享解锁功能 |
| 邀请好友加速合成/获得奖励 | 属于诱导分享，违规 |
| 使用道具前必须看广告 | 强制广告触发，违规 |
| 激励视频未完整播放发放奖励 | 流量主规范明确违规 |
| 诱导用户反复点击广告 | 违规，会导致广告主账户被封 |
| 通过利益诱惑引导用户分享 | 微信禁止，违规 |

### 2.2 合规分享设计

**允许的分享形式（不绑定功能奖励）：**

| 分享内容 | 触发场景 | 形式 |
|---------|---------|------|
| 战绩分享图 | 通关后弹出 | 可选，不发奖励 |
| 恐龙明信片/收藏卡 | 解锁新恐龙时 | 可选，不发奖励 |
| 排行榜炫耀图 | 进入排行榜时 | 可选，不发奖励 |
| 邀请好友提示 | 入口提示 | 仅提示，不奖励 |

> 所有分享均为**用户主动选择**的行为，不以任何游戏内奖励为交换条件。

### 2.3 合规广告设计原则

- 所有激励广告必须是用户**主动点击触发**
- 奖励必须在广告**完整播放后100%发放**
- 广告不可出现在功能流程的必经之路上
- 每日激励视频次数不设硬上限，但也不刻意引导多次观看

## 3. 核心玩法

### 3.1 九宫格合成规则

```
+---+---+---+
| A │ B │ C |   ← 随机掉落恐龙
+---+---+---+
| D │ E │ F |   ← 拖拽相同等级 → 合成 Lv.+1
+---+---+---+
| G │ H │ I |
+---+---+---+
```

**基础规则：**
1. 棋盘初始随机生成 3～5 只恐龙（以 Lv.1 为主）
2. 玩家拖拽一只恐龙到另一只**同等级**恐龙上 → 合成 Lv.+1
3. 每次操作后随机在空位掉落 1 只新恐龙（Lv.1 概率最高）
4. 棋盘满且无相同等级可合成 → 关卡失败
5. 恐龙最高 Lv.19

**拖拽交互规范：**
- 长按/点击选中 → 恐龙浮起 + 目标格高亮（150ms）
- 拖拽到目标格 → 满足则合成，不满足则弹回原位（300ms）
- 合成动画：金光扩散 + 星星粒子（500ms）
- 合成音效：清脆"叮"声

### 3.2 关卡设计

**目标规则：**
- 每关设定一个合成目标，如"合成 1 只 Lv.3"
- 达成目标 → 通关；棋盘满且无法合成 → 失败

**难度曲线：**
- 第1关：引导关，3步内完成，无失败
- 第2～3关：简单，Lv.1 合成 Lv.2，失败率 <5%
- 第4～10关：中等，失败率 15%～25%
- 第11～30关：困难，失败率 30%～45%
- 第31关+：挑战，失败率 45%以上

### 3.3 关卡参数表（开发核心数值）

| 关卡段 | 目标 | 初始恐龙数 | Lv.1 掉落概率 | Lv.2 掉落概率 | 目标失败率 | 广告触发点 |
|--------|------|-----------|--------------|--------------|-----------|----------|
| 1 | 合成 1 只 Lv.2 | 3只 | 100% | 0% | <5% | 无（引导关） |
| 2～3 | 合成 1 只 Lv.3 | 4只 | 95% | 5% | <5% | 失败后激励视频 |
| 4～10 | 合成 1 只 Lv.4 | 4～5只 | 80% | 18% | 15%～25% | 失败后激励视频 |
| 11～30 | 合成 1 只 Lv.5 | 5～6只 | 动态 | 动态 | 30%～45% | 道具/复活激励视频 |
| 31+ | 合成更高等级 | 6只+ | 动态 | 动态 | 45%+ | 道具/复活激励视频 |

**掉落概率说明：**
- Lv.1 掉落概率随关卡递减（高关卡出现更多 Lv.2/Lv.3）
- 采用种子关卡（伪随机，保证同一关卡每次体验一致）
- 失败率通过数值工具模拟调整，目标让 70% 用户在第 5～15 关卡关

### 3.4 失败判断逻辑

```
每步操作后执行：
1. 检查是否达成通关目标 → 是 → 通关结算
2. 检查是否有空位 → 否 → 进入步骤3
3. 检查是否有相同等级可合成 → 是 → 继续游戏
4. → 否 → 触发失败面板
```

## 4. 广告变现设计

### 4.1 合规广告点（仅此3个）

| 广告点 | 触发时机 | 用户行为 | 广告类型 | 奖励 |
|--------|---------|---------|---------|------|
| **失败复活** | 棋盘满且无法合成时弹出失败面板 | 用户主动点击"观看广告复活"按钮 | 激励视频（30s） | 复活继续当前关卡，清空棋盘重新开始 |
| **额外道具** | 当日免费道具次数已用完，用户点击使用道具 | 用户主动点击"看广告获得道具" | 激励视频（30s） | 补发当日该道具1次 |
| **双倍奖励** | 通关结算面板弹出时 | 用户主动点击"看广告双倍领取" | 激励视频（30s） | 金币/碎片翻倍 |

> **核心原则**：广告是用户主动选择的服务延伸，不是功能门槛。用户永远有"不看广告"的选择权（只是不拿奖励）。

### 4.2 广告触发频率控制

- 每个广告点**每天不设硬上限**
- 失败复活：**每次失败都可触发**，但用户可选择直接重开来放弃广告
- 额外道具：**用完才可触发**，不重复弹窗
- 双倍奖励：**仅通关时出现一次**

### 4.3 激励视频合规要点

- 广告完整播放前不发放奖励
- 广告播放失败时显示"网络异常，请重试"，不影响用户继续游戏
- 不出现任何诱导点击广告的文案（如"再看一次获取更多"）
- 广告加载失败不阻塞游戏流程

### 4.4 其他广告位（次要）

| 广告位 | 场景 | 类型 | 频率 |
|--------|------|------|------|
| 插屏广告 | 每5关通关后弹出 | 插屏（5-15s） | 每5关1次 |
| Banner | 主界面底部 | Banner | 持续展示 |

> 插屏广告频率不可过高，避免用户反感。

## 5. 道具系统

### 5.1 三个基础道具（每日免费1次）

| 道具 | 图标 | 效果 | 免费次数 | 广告追加 |
|------|------|------|---------|---------|
| 移除道具 | 蓝色圆圈+闪电 | 将任意一只恐龙移出棋盘到一旁 | 1次/天 | 用完可看广告补1次 |
| 撤回道具 | 粉色卡片+星星 | 回退最近1步操作 | 1次/天 | 用完可看广告补1次 |
| 洗牌道具 | 绿色布袋+恐龙 | 随机打乱棋盘所有恐龙位置 | 1次/天 | 用完可看广告补1次 |

**设计原则：**
- 每种道具每天给 **1次免费使用机会**
- 免费次数用完后，**不再弹出广告提示**，用户需主动点击道具按钮才会触发"看广告补次数"
- 道具是**改善体验的工具**，不是必须，不影响通关

### 5.2 道具使用流程

```
用户点击道具按钮
    │
    ├── 当日免费次数 > 0
    │       │
    │       └── 直接使用，免费
    │
    └── 当日免费次数 = 0
            │
            └── 用户可选择：
                    ├── "看广告获取" → 播放激励视频 → 获得1次
                    └── "不用了" → 关闭面板
```

## 6. 社交与分享（合规设计）

### 6.1 分享功能（无奖励）

| 分享类型 | 触发场景 | 内容形式 |
|---------|---------|---------|
| 战绩分享图 | 通关后弹出面板 | 展示通关关卡数 + 最高合成恐龙等级 |
| 恐龙收藏卡 | 解锁新恐龙时 | 生成精美恐龙卡片图 |
| 排行榜炫耀 | 查看排行榜时 | 当前排名截图 |
| 再来一局 | 失败面板 | 快速重开（不涉及分享奖励） |

**所有分享均不发放任何游戏内奖励**。分享是用户自发行为，不是功能前提。

### 6.2 排行榜（无激励）

- 全国排行榜：按累计通关关数排序
- 好友排行榜：展示微信好友通关进度
- 不设地区分组（避免地域竞争引发监管问题）
- 不设分享后排名上升机制

## 7. 图鉴收集系统

### 7.1 恐龙图鉴

- 共 19 个等级（Lv.1 ～ Lv.19）
- 首次合成某等级恐龙 → 自动解锁图鉴
- 图鉴展示：恐龙图片 + 等级 + 颜色 + 首次解锁时间
- 图鉴是**进度展示**，不绑定任何功能奖励

### 7.2 变异稀有恐龙（可选炫耀元素）

- 合成时有小概率（<5%）触发"变异"
- 变异恐龙有特殊外观（发光/星星围绕）
- 仅影响视觉展示，不影响数值
- 解锁变异恐龙可生成"收藏卡"分享

## 10. 验收标准与数据指标

### 10.1 功能验收标准

| 模块 | 验收标准 |
|------|---------|
| 合成动画 | 拖拽到目标格后300ms内完成合成，目标格生成Lv.+1恐龙 |
| 失败判断 | 棋盘满且无相同等级可合成时，弹出失败面板，误判率<0.1% |
| 道具发放 | 广告完整观看后100%发放，每日次数正确刷新 |
| 奖励发放 | 广告完整播放后100%发放奖励，失败时显示"网络异常"并允许重试 |
| 图鉴解锁 | 首次合成某等级后，图鉴对应条目自动点亮，无延迟 |
| 重开 | 点击"重开"后，棋盘清空，按当前关卡初始配置重新开始 |

### 10.2 核心数据指标（目标值）

| 指标 | 目标值 | 说明 |
|------|--------|------|
| D1 留存 | 25%～35% | 次日回访率 |
| D7 留存 | 10%～15% | 一周回访率 |
| 人均局数 | 5～8 局/日 | 每用户每日完成游戏局数 |
| 首局完成率 | 90%+ | 第1关通关率 |
| 第2～3关失败率 | 20%～35% | 早期留存关键 |
| 激励视频触发率 | 30%～50% | 失败后点击看广告的比例 |
| 激励视频完成率 | 70%+ | 广告完整播放率 |
| 单用户日均广告次数 | 2～5 次 | 广告变现效率指标 |
| 插屏广告点击率 | <3% | 过高会影响留存 |
| 分享率（无奖励） | 3%～8% | 自发分享率 |

### 10.3 数据埋点（关键事件）

| 事件名称 | 触发时机 | 携带参数 |
|---------|---------|---------|
| game_start | 点击开始游戏 | level_id |
| game_over | 关卡结束 | level_id, is_win, reason |
| merge | 合成发生时 | from_level, to_level, position |
|道具_use | 道具使用时 | 道具类型, is_free, level_id |
| ad_request | 请求广告时 | ad_type, position |
| ad_complete | 广告完整播放 | ad_type, reward_type |
| ad_skip | 广告跳过/失败 | ad_type, reason |
| share_click | 点击分享 | share_type |
| level_complete | 通关 | level_id, attempts |

## 11. 技术要求

### 11.1 平台
- 微信小程序（小游戏）
- 适配：iOS / Android
- 最低微信版本：8.0+

### 11.2 性能目标
- 首屏加载 < 3秒
- 帧率：60 FPS
- 包体大小：< 5MB（含基础资源）

### 11.3 广告接入
- `wx.createRewardedVideoAd()` — 激励视频
- `wx.createInterstitialAd()` — 插屏广告（每5关1次）
- 微信广告平台申请（个人开发者可申请）

### 11.4 数据存储
- 本地：`localStorage` 或 `wx.setStorageSync()`
- 云端：微信云开发（可选，用于排行榜）
