# 萌萌合成小恐龙

> 微信小游戏 · 广告变现 · Q版合成玩法

## 项目信息

- **项目名称**：萌萌合成小恐龙
- **仓库**：https://github.com/DXinLei/wechat_game
- **当前分支**：feat/p0-mvp-bootstrap
- **当前阶段**：P0 MVP 工程初始化

## 如何打开

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本仓库根目录
3. AppID 选择"测试号"（touristappid）
4. 点击"导入"，等待编译完成
